# MGMT298D Case Document Style Guide

## Overview

This style guide ensures consistency across all case documents for MGMT298D: Science and Strategy of AI. The formatting mirrors the slide deck style guide to create a cohesive visual identity across course materials.

---

## Color Palette

| Name | Hex | Usage |
|------|-----|-------|
| Dark Blue | #005587 | Titles, section headings, question headings |
| Gold | #FFD100 | Accent line under header |
| Body Text | #333333 | Main paragraph text |
| Gray | #666666 | Header line, week subtitle, sources |

---

## Typography

### Fonts

| Element | Font | Size | Weight | Color |
|---------|------|------|--------|-------|

| Section headings | Whitney | 14pt | Bold | Dark Blue |
| Question headings | Arial | 12pt | Bold | Dark Blue |
| Body text | Arial | 12pt | Regular | Body Text (#333333) |
| Header line | Arial | 10pt | Italic | Gray |
| Week subtitle | Arial | 11pt | Italic | Gray |
| Sources | Arial | 10pt | Regular | Gray |

### Font Fallbacks

If Whitney is unavailable, use:
1. Helvetica Neue
2. Arial
3. Sans-serif

---

## Page Layout

- **Page size**: US Letter (8.5" × 11")
- **Margins**: 1" all sides
- **Line spacing**: 1.15 for body text
- **Paragraph spacing**: 10pt after paragraphs

---

## Document Structure

### 1. Header Line
- Course identifier: "MGMT298D: Science and Strategy of AI | UCLA Anderson"
- Font: Arial, 10pt, italic, gray (#666666)
- Gold (#FFD100) underline rule beneath

### 2. Document Title
- Case name as main title
- Font: Whitney, 20pt, bold, dark blue (#005587)
- Spacing: 18pt before, 12pt after

### 3. Week Subtitle
- Format: "Week N: Topic Name"
- Font: Arial, 11pt, italic, gray (#666666)
- Spacing: 3pt before, 18pt after

### 4. Section Headings
- Examples: "The Situation", "Key Insights", "Discussion Questions", "Sources"
- Font: Whitney, 14pt, bold, dark blue (#005587)
- Spacing: 15pt before, 9pt after

### 5. Question Headings
- Format: "Question 1", "Question 2", etc.
- Font: Arial, 12pt, bold, dark blue (#005587)
- Spacing: 12pt before, 6pt after

### 6. Body Paragraphs
- Font: Arial, 12pt, regular, body text (#333333)
- Line spacing: 1.15
- Spacing: 10pt after each paragraph

### 7. Sources Section
- Font: Arial, 10pt, regular, gray (#666666)
- Spacing: 6pt after each source
- Format: "Title." Publication, Date. url

---

## Standard Sections

Every case document should include these sections in order:

1. **Header line** — Course identifier with gold underline
2. **Title** — Case name
3. **Week subtitle** — Week number and topic
4. **Narrative sections** — Typically 2-4 sections describing the situation
   - Use descriptive headings (e.g., "The Situation", "Company Name's Approach", "Key Insights")
5. **Discussion Questions** — Section heading followed by numbered questions
   - Use "Question 1", "Question 2" format for subheadings
   - Each question as its own paragraph
6. **Sources** — Citations in consistent format

## Formatting Examples

### Header Block
```
MGMT298D: Science and Strategy of AI | UCLA Anderson
────────────────────────────────────────────────────── (gold line)

H&M: AI-Powered Demand Forecasting

Week 1: Linear Regression
```

### Section with Body Text
```
The Situation

H&M, one of the world's largest fashion retailers, faced a crisis 
familiar to the industry: billions of dollars in unsold inventory...
```

### Discussion Questions
```
Discussion Questions

Question 1

H&M trains on years of historical data but retrains frequently. 
Why is this combination of long history and frequent updates 
important for demand forecasting?

Question 2

H&M forecasts demand at the item-store-size-color level. What are 
the trade-offs between granular and aggregate forecasting?
```

### Sources
```
Sources

"H&M Leaves $4.3 Billion In Unsold Inventory On The Racks." NPR, 
March 28, 2018. npr.org

"H&M's AI operation helps make its supply chain more sustainable." 
Retail Dive, January 15, 2020. retaildive.com
```
