# MGMT298D Slide Style Guide

## Overview

These slides are for **MGMT298D: Science and Strategy of AI** at UCLA Anderson School of Management, taught by Auyon Siddiq. The course is aimed at non-technical MBA students. Each week covers a core ML/AI topic with an emphasis on intuition over math.

The presentations are built from scratch using **pptxgenjs** (Node.js). Layout is **16:9**.

## Slide Types

### 1. Title Slide
- **Background:** solid dark blue (`005587`)
- **Layout (top to bottom):**
  - y=1.0: "MGMT298D" — 16pt gold, centered
  - y=1.3: "Science and Strategy of AI" — 14pt gold, centered
  - y=1.85: "Week N" — 20pt white bold, centered
  - y=2.25: Main title (two lines) — 34pt white bold, centered
  - y=3.8: "UCLA Anderson School of Management" — 12pt white, centered
  - y=4.1: "Auyon Siddiq" — 14pt white bold, centered

### 2. Section Divider
- **Background:** solid dark blue (`005587`)
- **Text:** centered both ways, 36pt (or 32pt for shorter text), gold, bold + italic
- **Position:** x:0.5, y:1.5, w:9.0, h:2.5

### 3. Case Handout Divider
- Same as section divider but with two text blocks:
  - "Case Handout" — 28pt white, centered
  - Case title — 36pt gold bold italic, centered

### 4. Standard Content Slide
- **Background:** white
- **Left accent bar:** 0.06" wide, full height, dark blue
- **Title:** 28pt dark blue bold, positioned at top
- **Gray rule:** thin line under title
- **Body:** starts at y ≈ 1.1", bullets at 15pt, left-aligned
- **Bullet style:** standard bullet points; use `indentLevel: 1` for sub-items
- **Spacing:** `paraSpaceAfter: 4` default; use `space: 5–6` for visual grouping between sections

### 5. Table Slide
- Same header as content slide
- **Table positioning:** x:0.5", y varies (typically 1.5"–1.8"), w:9.0"
- **Table styling:**
  - Header row: fill `005587`, text white bold, 11–13pt
  - Alternating rows: fill `EDF2F7` on even rows
  - Border: 0.5pt, color `CCCCCC`
  - Cell margin: `[3,5,3,5]` or `[4,6,4,6]` (top, right, bottom, left in points)
- **Below table:** often an italic annotation in gray, or a callout box

### 6. Callout Box
- **Blue callout:** background `EBF5FB`, text `005587` bold, 13pt
- **Amber callout:** background `FFF8E1`, text `C4820E` bold, 13pt
- **Dimensions:** full content width (9.0"), height 0.45"
- **Text inset:** 0.15" from left edge of box

## Pedagogical Style Rules

These are the content principles that make these slides effective for MBA students:

### One Concept Per Slide
Each slide covers one idea. Never combine multiple topics. If a topic has 3 steps, give each step its own slide.

### Brief Bullet Points
Keep bullets to one line where possible (two max). No paragraphs. Tighten language aggressively.

### Numerical Walkthroughs
Every algorithm or concept should have a dedicated **numerical example slide** showing step-by-step calculations with real numbers. These are the most important slides for student comprehension.

**Pattern:**
1. Introduce the concept on one slide (brief bullets)
2. Show the math/example on the next slide (table with calculations)
3. Annotate what the numbers mean below the table

**Examples of numerical walkthroughs we've used:**
- Regression: feature × coefficient table showing ŷ = 138 units
- Loss functions: 3 products showing MAE vs MSE calculations
- LASSO: coefficient table across 4 λ values showing features dropping to zero
- Cross-validation: 5-fold table across 3 λ candidates
- Boosting: step-by-step residual → η × tree → new prediction table
- XGBoost tuning: 4 configurations comparing train/test MAE
- K-Means: 4 users with distance calculations and centroid updates
- Cosine similarity: full dot product and magnitude calculation
- CF prediction: weighted average rating calculation

### Hyperparameter Tables
Every algorithm section should have a **dedicated hyperparameter slide** as a reference table:

| Parameter | What It Controls | Typical Values | Effect / Trade-off |
|-----------|-----------------|----------------|-------------------|

Include 5–8 parameters. Add an italic footer noting which 1–2 are most important to tune.

### Section Structure
Each algorithm section follows this pattern:
1. **Section divider** (dark blue bg, gold text)
2. **Concept overview** (what it does, why it matters — brief bullets)
3. **How it works** (mechanics, maybe a diagram with shapes)
4. **Numerical example** (step-by-step table with real numbers)
5. **Hyperparameters** (reference table)
6. **Practical considerations** (when to use, trade-offs, limitations)

### Emphasis Patterns
- **Bold + dark blue** for key terms and section labels within bullet lists
- **Red** (`CC0000`) for warnings, overfit indicators, things that go wrong
- **Gray italic** for annotations, footnotes, "in practice" notes
- **Callout boxes** for key takeaways or "bottom line" statements

### Slide Count
Typical presentation: **27–33 slides** including title, case handout divider, section dividers, Colab demo, and assignment slides.

## Common Patterns (Code Reference)

### Table with alternating rows
```javascript
let rows = [
  // Header row
  [{text:"Col A", options:{bold:true, color:"FFFFFF", fill:{color:"005587"}, fontSize:12, align:"center"}},
   {text:"Col B", options:{bold:true, color:"FFFFFF", fill:{color:"005587"}, fontSize:12, align:"center"}}],
  // Data row (alt background)
  [{text:"val", options:{fontSize:12, fill:{color:"EDF2F7"}}},
   {text:"val", options:{fontSize:12, fill:{color:"EDF2F7"}}}],
  // Data row (white background — just omit fill)
  [{text:"val", options:{fontSize:12}},
   {text:"val", options:{fontSize:12}}],
];
slide.addTable(rows, {
  x:0.5, y:1.5, w:9.0, h:2.0,
  colW:[4.5, 4.5],
  border:{pt:0.5, color:"CCCCCC"},
  margin:[4,6,4,6]
});
```

### Callout box
```javascript
// Blue (insight/takeaway)
slide.addShape(pres.shapes.RECTANGLE, {x:0.5, y:4.2, w:9.0, h:0.45, fill:{color:"EBF5FB"}});
slide.addText("Key insight text here", {x:0.65, y:4.2, w:8.7, h:0.45, fontSize:13, fontFace:"Arial", color:"005587", bold:true, valign:"middle"});

// Amber (warning/nuance)
slide.addShape(pres.shapes.RECTANGLE, {x:0.5, y:4.2, w:9.0, h:0.45, fill:{color:"FFF8E1"}});
slide.addText("Warning text here", {x:0.65, y:4.2, w:8.7, h:0.45, fontSize:13, fontFace:"Arial", color:"C4820E", bold:true, valign:"middle"});
```

### Horizontal bar chart (feature importance style)
```javascript
let features = [
  {name:"Feature A", pct:28, barW:4.0},
  {name:"Feature B", pct:22, barW:3.15},
];
features.forEach((f, i) => {
  let y = startY + i * 0.35;
  slide.addText(f.name, {x:0.5, y:y, w:1.5, h:0.3, fontSize:11, fontFace:"Arial", color:"333333", align:"right", valign:"middle"});
  slide.addShape(pres.shapes.RECTANGLE, {x:2.1, y:y+0.03, w:f.barW, h:0.24, fill:{color:"2774AE"}});
  slide.addText(f.pct+"%", {x:2.1+f.barW+0.1, y:y, w:0.6, h:0.3, fontSize:11, fontFace:"Arial", color:"005587", bold:true, valign:"middle"});
});
```

### Train/test split visual bar
```javascript
slide.addShape(pres.shapes.RECTANGLE, {x:0.5, y:1.7, w:6.3, h:0.5, fill:{color:"2774AE"}});
slide.addText("Training Data (70–80%)", {x:0.5, y:1.7, w:6.3, h:0.5, fontSize:14, fontFace:"Arial", color:"FFFFFF", bold:true, align:"center", valign:"middle"});
slide.addShape(pres.shapes.RECTANGLE, {x:6.8, y:1.7, w:2.7, h:0.5, fill:{color:"FFD100"}});
slide.addText("Test Data (20–30%)", {x:6.8, y:1.7, w:2.7, h:0.5, fontSize:13, fontFace:"Arial", color:"005587", bold:true, align:"center", valign:"middle"});
```

## QA Checklist

After building, always:

1. **Convert to PDF + images:**
   ```bash
   python /mnt/skills/public/pptx/scripts/office/soffice.py --headless --convert-to pdf output.pptx
   pdftoppm -jpeg -r 150 output.pdf slide
   ```
2. **Generate thumbnail grid:**
   ```bash
   python /mnt/skills/public/pptx/scripts/thumbnail.py output.pptx thumbs --cols 4
   ```
3. **Visually inspect** all slides via thumbnail grids — check for overlapping text, cut-off tables, spacing issues.
4. **Spot-check** key slides (numerical examples, tables) at full resolution.
5. **Verify slide count** matches expectations.
